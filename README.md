
# Shob Sheba

Shob Sheba is a simple and user-friendly platform that helps people find information about different government services in Bangladesh.

Users can learn about service requirements, required documents, application steps, fees, and official government websites from one place.

## Live Demo

[Visit Shob Sheba](https://shob-sheba.vercel.app/)

## Features

- Simple and clean user interface.
- Browse popular government services.
- Search for services by name or keywords.
- View detailed information about each service.
- Check eligibility requirements.
- See the list of required documents.
- Follow step-by-step application instructions.
- Get information about government fees and processing times.
- Visit official government websites directly.
- Responsive design for mobile, tablet, and desktop.
- Login and registration UI.

## How the Key Features Work

- **Browse Services:** Users can explore popular government services in Bangladesh and find relevant service information.
- **Search Services:** Users can search for specific services using service names or related keywords.
- **Service Details:** Each service has a dedicated details page containing eligibility criteria, required documents, application procedures, fees, and estimated processing times.
- **Eligibility & Documents:** Users can check whether they meet the requirements and understand which documents they need before applying.
- **Step-by-Step Guidance:** Users can follow clear instructions to understand how to complete each service application.
- **Official Website Access:** Users can directly visit the relevant government websites through the provided official links.
- **Authentication UI:** Users can access the login and registration interfaces.
- **Responsive Design:** The platform adapts to different screen sizes, providing a consistent experience across mobile, tablet, and desktop devices.

## Run Locally

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/Eva-004/shob-sheba
```

### 2. Go to the Project Folder

```bash
cd shob-sheba
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```

## Important Note

Shob Sheba is an informational platform, not an official government website or service provider.

All service information is provided to help users understand the application process. Users should always check the relevant official government website for the latest information before applying.
